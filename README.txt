FunCam — put it on your phone (about 5 minutes)

1. On github.com make a new repository (any name, e.g. "funcam-x7k"). Public is fine:
   the repo only holds the app's code. Your photos/videos never go there.
2. Upload ALL files from this folder (flat, no sub-folders): "Add file" > "Upload files".
3. Settings > Pages > "Deploy from a branch" > main / (root) > Save. Wait a minute.
4. On your Android phone open  https://YOURNAME.github.io/REPO-NAME/  in Chrome.
5. Chrome menu (three dots) > "Install app" (or "Add to Home screen").
6. Open it from the home-screen icon, allow Camera, then Settings > Set PIN.

To update later: upload changed files and bump VERSION in sw.js.
